WHAT IS ML?

DEFINITION

COMPUTERS LEARN

Machine learning (ML) is a type of artificial intelligence that enables computers to learn from data without being explicitly programmed for every task.

LEARNING APPROACHES

THREE WAYS
TO LEARN

Machine learning can use different approaches depending on the type of data available and how the system is expected to learn.

01 • SUPERVISED

SUPERVISED LEARNING

Uses data that already has correct answers or labels. For example, a model could learn from pictures labelled "cat" and "dog."

02 • UNSUPERVISED

UNSUPERVISED LEARNING

Uses data without labels and attempts to discover patterns, relationships, or groups on its own.

+
03 • REINFORCEMENT

REINFORCEMENT LEARNING

Learns through rewards and penalties, helping a system discover which actions are more likely to produce a good result.
